# 蔡宜恬 · 游戏文案与叙事策划作品集

个人作品网站，展示叙事策划项目、游戏分析、试玩演示与简历。

## 在线访问

https://christian-rum.github.io/cai-yitian-portfolio/

## 本地预览

打开 `dist/index.html` 即可预览。网站使用静态 HTML、CSS 和 JavaScript，无需安装依赖。

## 发布更新

先把修改提交并推送到 `main`，然后运行 `git subtree push --prefix dist origin gh-pages`。GitHub Pages 从 `gh-pages` 分支的根目录发布网站。

## 隐私与撤下

网站和仓库公开时，链接及文件可供他人访问。招聘结束后，可在仓库设置中取消发布 GitHub Pages，并将仓库改为私有；仅取消发布页面不会隐藏仓库中的文件。
